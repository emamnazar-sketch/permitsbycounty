Coverage: this report covers building permits issued by the City of Orlando. Orange County's unincorporated permits run through a separate county system and are not in this feed, so totals here are Orlando totals — labeled as such, never blended. Two facts about the city's data shape the figures. The dataset is the city's permit applications register, so this report counts only applications the city actually issued — each one carries the issue date the city recorded. And project values are the applicants' estimated costs, printed as reported: identical buildings in one development can state the same estimated cost on each of their permits.
