Fastest movers

Ranked by permits issued, big counties sit on top. Ranked by change, these five picked up the most speed in October:

  • Wayne County (Detroit), MI — up 25.0% (2,161 in September, 2,702 in October)

  • Bronx County, NY — up 14.5% (1,319 in September, 1,510 in October)
  • Philadelphia County, PA — up 10.3% (3,676 in September, 4,054 in October)

Where these numbers come from

Every count comes from that county’s own report on this site, built from official public records — the same monthly table you see at the top of each report. One honest caution: counties count permits a little differently (one place says building permits, another says construction permits), so read this as a guide to where the work is moving, not a perfect apples-to-apples count. November 2026 is still a partial month in every report, so it is not ranked here. This page is rebuilt each month when the new full month lands.
